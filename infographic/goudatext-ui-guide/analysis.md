## Main Topic

以一张竖版信息图说明 GoudaText Gunpla Showcase 的视觉定位、设计 Token、页面结构、响应式规则、交互和可访问性。

## Learning Objectives

观看后应理解：

1. GoudaText 的“装甲档案系统”视觉定位。
2. 色彩、字体、布局和页面模块如何组成统一界面。
3. 动效、响应式和可访问性约束如何保证生产质量。

## Target Audience

- **Knowledge Level**: 具备基础 UI 或前端知识。
- **Context**: 设计评审、开发交接、品牌视觉速览。
- **Expectations**: 在一分钟内掌握核心视觉规则和实现参数。

## Content Type Analysis

- **Data Structure**: 七组并列设计模块，包含层级关系和精确参数。
- **Key Relationships**: 品牌定位约束 Token；Token 驱动页面结构；响应式与可访问性约束最终表现。
- **Visual Opportunities**: 色板、字体权重刻度、页面缩略图、断点尺寸、焦点和动效参数。

## Layout x Style Signals

- 系统概览适合 `dense-modules`。
- 模型工作室与精确参数适合 `technical-schematic`。
- 现有品牌要求覆盖该风格的默认蓝色，用 GoudaText 黑、黄、骨白、红替代。

## Design Instructions

- 竖版 `9:16`，中文。
- 使用实际页面截图作为视觉证据。
- 保持高对比装甲档案风格，不生成蓝图蓝、霓虹或抽象装饰。

## Recommended Combinations

1. **dense-modules + technical-schematic**：最适合参数化视觉规范。
2. **structural-breakdown + technical-schematic**：适合强调界面解剖，但信息覆盖较少。
3. **bento-grid + bold-graphic**：易读但会削弱现有品牌的精密感。
